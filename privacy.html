Privacy Policy

Paradox ATS Bulk Tools · Last updated: September 3, 2026

Overview

Paradox ATS Bulk Tools is a Chrome extension that helps recruiters perform bulk resume downloads and candidate disposition on Paradox.ai. Your privacy is important to us, and this policy explains what data the extension accesses and how it is handled.

Data Collection

This extension collects a small amount of anonymous usage data so the team can measure how the tool is used. When you open the panel, scan for candidates, download resumes, or disposition candidates, the extension sends an event containing: a random identifier generated once per browser install (not linked to your name, email, or any account), the action taken, the number of candidates involved, whether the download was a zip or merged PDF, the extension version, the browser (Chrome or Edge), and the Paradox subdomain.

No candidate names, resume content, search terms, personal information, or browsing history is ever collected or transmitted. The random identifier is stored only in the extension's local storage and is removed when you uninstall the extension.

Data Access

The extension accesses data on Paradox.ai domains (*.paradox.ai) solely to perform the actions you initiate — scanning candidate lists, downloading resumes, and updating candidate statuses. All API requests use your existing Paradox.ai session credentials (cookies). The extension does not store or cache any candidate data, resumes, or credentials beyond the active browser session.

Permissions

The extension requests the following permissions:

storage: To keep the random anonymous install identifier described above.

downloads: To save resume files (PDFs and zip archives) to your computer.

host_permissions (*.paradox.ai): To make API requests to Paradox.ai on your behalf using your existing session.

Resume Files

When you download resumes, the PDF files are saved directly to your computer's downloads folder. The extension does not upload, copy, or transmit resume files to any external server. Merged PDFs are assembled entirely in your browser's memory and saved locally.

Third-Party Services

Anonymous usage events are sent to a Google Apps Script endpoint controlled by the extension developer and stored in a private Google Sheet. This data is used only to report aggregate usage, such as the number of active users per week and the number of resumes downloaded. It is never sold, shared with third parties, or used for advertising. Aside from this, the extension communicates only with Paradox.ai.

Changes to This Policy

If this privacy policy is updated, the changes will be posted on this page with an updated date.
